Project 1: Xero Bookkeeping Workflow

Fictional data. Practice demonstration, not client work.

Scenario: Harbor Lane Studio, a fictional design studio, needs March records organized.
Objective: Record sales and expenses, categorize correctly, close the month.
Tools: Xero (practice file), Excel/Google Sheets.

Sample chart of accounts

Code Account Type
200 Sales - Design Services Revenue
210 Sales - Retainers Revenue
400 Software Subscriptions Expense
410 Marketing Expense
610 Accounts Receivable Asset
800 Accounts Payable Liability

Workflow

  1. Collect invoices and receipts.
  2. Enter and categorize.
  3. Post to ledger.
  4. Reconcile.
  5. Run reports.
  6. Month-end checklist.

Month-end checklist

  • All bank lines coded
  • Reconciled
  • AR/AP reviewed
  • Reports run
  • Questions logged

Deliverables

Chart of accounts, categorized transactions (see data/sample-transactions.csv), ledger, checklist.
Journal check: INV-1001 debit 1,100.00 = credit 1,000.00 + 100.00.

Key findings

Consistent coding up front saves reconciliation time. Every entry needs a reference number.
