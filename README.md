# Xero Bookkeeping Portfolio — Nancy Flores
Portfolio of a remote bookkeeper (Xero, QuickBooks Online, Xero Payroll) for small businesses, property managers and agencies.

> **All data is fictional.** Projects are practice demonstrations, not client work. Not affiliated with Xero or Intuit.

## Features
Responsive site, five case studies, CSS/JS charts, workflow diagram, skills matrix, no backend.
## Projects
See `projects/`. **Stack:** HTML5, CSS3, vanilla JS.
## Structure
`index.html`, `css/`, `js/`, `assets/`, `projects/`, `data/`, `README.md`
## Run locally
Open `index.html`, or run `python -m http.server` and visit http://localhost:8000
## Publish
GitHub repo → Settings → Pages → Deploy from branch `main` / root.
